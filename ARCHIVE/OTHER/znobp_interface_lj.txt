# Lennard-Jones (12-6) interlayer cross-terms:  ZnO <-> Black Phosphorus
# For LAMMPS lj/cut inside a hybrid/overlay style.  Units: metal (eV, A).
#
# BUILT PER YOUR CHOSEN SOURCE (UFF / GitHub .def convention):
#   - Single-element params: UFF, Rappe et al. JACS 114, 10024 (1992).
#   - Conversions (from the GitHub note):
#         sigma  = Rmin / 2^(1/6)
#         eps[K] = D0[kcal/mol] / 0.0019872041
#     then to metal units:  eps[eV] = eps[K] * 8.617333e-5
#   - Mixing rule: LORENTZ-BERTHELOT  (as declared in the .def file):
#         sigma_ij = (sigma_i + sigma_j)/2
#         eps_ij   = sqrt(eps_i * eps_j)
#
# Single-element values used:
#   Zn:  Rmin=2.763, D0=0.124 -> sigma=2.46155 A, eps=0.0053771 eV
#   O :  Rmin=3.500, D0=0.060 -> sigma=3.11815 A, eps=0.0026018 eV
#   P :  Rmin=4.147, D0=0.305 -> sigma=3.69456 A, eps=0.0132261 eV
#
# FINAL CROSS-TERMS (Lorentz-Berthelot):
#   P-Zn :  eps = 0.0084332 eV ,  sigma = 3.07806 A
#   P-O  :  eps = 0.0058662 eV ,  sigma = 3.40635 A
# =============================================================================
# pair_coeff LINES  (example numbering -- ADJUST to your data file).
# BP has TWO P sub-types (T=top, B=bottom pucker) so each term is written twice.
# Example: Zn=type1, O=type2, P(T)=type3, P(B)=type4.  LAMMPS requires i<=j.
#
#   pair_coeff 1 3 lj/cut 0.0084332 3.07806   # Zn - P(T)
#   pair_coeff 1 4 lj/cut 0.0084332 3.07806   # Zn - P(B)
#   pair_coeff 2 3 lj/cut 0.0058662 3.40635   # O  - P(T)
#   pair_coeff 2 4 lj/cut 0.0058662 3.40635   # O  - P(B)
# =============================================================================
